🔌 Tài liệu API cho khách

Trang này hướng dẫn cách kết nối hệ thống của bạn (panel, phần mềm, website riêng) với Việt Tương Tác để xem danh sách gói và giá, đặt đơn, xem số dư ví và tra trạng thái đơn — mọi thứ tự động, dùng chung ví và giá như khi đặt trên web.

1. Thông tin kết nối

Địa chỉ API (gửi yêu cầu bằng phương thức POST):

https://smm-proxy.hungcuonghnhm.workers.dev/api/v2

API theo chuẩn v2 giống các panel quốc tế. Mọi yêu cầu đều gồm 2 tham số bắt buộc:

Tham sốÝ nghĩa
keyKhóa API của tài khoản bạn (xem cách lấy ở mục 2)
actionTên lệnh muốn thực hiện: services, balance, add hoặc status

Gửi dữ liệu dạng form (application/x-www-form-urlencoded) hoặc JSON đều được. Kết quả trả về luôn là JSON.

2. Cách lấy khóa API

1. Đăng nhập vào tài khoản của bạn trên viettuongtac.com.
2. Mở trang Tài khoản, kéo xuống mục 🔌 Kết nối API.
3. Bấm tạo khóa — khóa đầy đủ chỉ hiện 1 lần duy nhất, bạn lưu lại ngay nhé.

Mỗi tài khoản có 1 khóa đang dùng. Bấm "Thay khóa" thì khóa cũ ngừng hoạt động ngay lập tức. Nếu nghi ngờ bị lộ khóa, thay khóa mới ngay trong trang Tài khoản. Quên khóa cũng chỉ cần tạo khóa mới, khóa cũ tự hết hiệu lực.

Tới trang Tài khoản lấy khóa

3. Danh sách lệnh

📋 services — Lấy danh sách gói và giá

Không cần tham số nào thêm ngoài key và action=services. Kết quả là danh sách toàn bộ gói đang bán, mỗi gói gồm:

TrườngÝ nghĩa
serviceMã gói — dùng mã này khi đặt đơn
nameTên gói
typeLoại gói (thường là Default; gói bình luận có loại riêng)
categoryNhóm dịch vụ (Facebook, TikTok, YouTube…)
rateGiá bán, tính bằng VNĐ cho 1.000 số lượng
min / maxSố lượng nhỏ nhất / lớn nhất được đặt cho 1 đơn
refilltrue = gói có hỗ trợ bảo hành tụt (chạy bù), false = không có
canceltrue = gói có hỗ trợ hủy đơn, false = không có
curl -X POST https://smm-proxy.hungcuonghnhm.workers.dev/api/v2 \
  -d "key=KHOA_API_CUA_BAN" \
  -d "action=services"

💰 balance — Xem số dư ví

curl -X POST https://smm-proxy.hungcuonghnhm.workers.dev/api/v2 \
  -d "key=KHOA_API_CUA_BAN" \
  -d "action=balance"

Kết quả mẫu:

{"balance": 250000, "currency": "VND"}

🛒 add — Đặt đơn

Tham sốBắt buộcÝ nghĩa
serviceCóMã gói (lấy từ lệnh services)
linkCóLink cần tăng (phải bắt đầu bằng http:// hoặc https://)
quantityCó*Số lượng cần đặt, nằm trong khoảng min–max của gói
commentsKhông*Chỉ dùng cho gói bình luận: mỗi bình luận viết 1 dòng; khi gửi comments thì số lượng tính theo số dòng, không cần gửi quantity
curl -X POST https://smm-proxy.hungcuonghnhm.workers.dev/api/v2 \
  -d "key=KHOA_API_CUA_BAN" \
  -d "action=add" \
  -d "service=948" \
  -d "link=https://www.facebook.com/viettuongtac" \
  -d "quantity=1000"

Kết quả mẫu khi đặt thành công — số trả về là mã đơn của shop, giữ lại để tra trạng thái:

{"order": 166}

Tiền được trừ từ ví của bạn, tính theo giá gói × số lượng ÷ 1.000. Nếu đơn bị lỗi ngay lúc đặt, tiền tự động hoàn về ví và API trả về nội dung lỗi tiếng Việt để bạn đọc.

🔍 status — Tra trạng thái đơn

Tham sốÝ nghĩa
orderMã đơn của shop (số nhận được khi đặt đơn qua API)
curl -X POST https://smm-proxy.hungcuonghnhm.workers.dev/api/v2 \
  -d "key=KHOA_API_CUA_BAN" \
  -d "action=status" \
  -d "order=166"

Kết quả mẫu:

{"status": "Completed", "charge": 9900, "start_count": 1200, "remains": 0, "currency": "VND"}
TrườngÝ nghĩa
statusTrạng thái đơn: Pending (chờ xử lý), Processing / In progress (đang chạy), Completed (hoàn thành), Partial (hoàn thành một phần, phần còn lại được hoàn tiền), Canceled (đã hủy, đã hoàn tiền)
chargeTổng tiền của đơn, tính bằng VNĐ
start_countSố đếm tại thời điểm bắt đầu chạy
remainsSố lượng còn lại chưa chạy

Mỗi khóa chỉ tra được đơn của chính tài khoản mình.

4. Ví dụ bằng PHP và Python

PHP — đặt một đơn:

<?php
$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL => "https://smm-proxy.hungcuonghnhm.workers.dev/api/v2",
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => [
        "key" => "KHOA_API_CUA_BAN",
        "action" => "add",
        "service" => 948,
        "link" => "https://www.facebook.com/viettuongtac",
        "quantity" => 1000,
    ],
]);
$res = json_decode(curl_exec($ch), true);
print_r($res); // ["order" => 166] khi đặt thành công

Python — xem số dư và tra trạng thái:

import requests

API = "https://smm-proxy.hungcuonghnhm.workers.dev/api/v2"
KEY = "KHOA_API_CUA_BAN"

print(requests.post(API, data={"key": KEY, "action": "balance"}).json())
print(requests.post(API, data={"key": KEY, "action": "status", "order": 166}).json())

5. Bảng mã lỗi

Lỗi trả vềNghĩa là gìCách xử lý
Invalid API key (401)Khóa không đúng, đã bị thay hoặc đã thu hồiMở trang Tài khoản, xem lại khóa đang dùng hoặc tạo khóa mới
Invalid action (400)Sai tên lệnhChỉ dùng 4 lệnh: services, balance, add, status
Invalid service / Invalid service or quantity (400)Mã gói không tồn tại hoặc số lượng không hợp lệLấy lại mã gói từ lệnh services
Invalid link (400)Link chưa đúng định dạngLink phải bắt đầu bằng http:// hoặc https://
Minimum quantity is X / Maximum quantity is X (400)Số lượng ngoài khoảng cho phép của góiĐặt trong khoảng min–max của gói đó
Insufficient balance (402)Số dư ví không đủ cho đơn nàyNạp thêm tiền vào ví rồi đặt lại
Daily API spend limit exceeded (403)Đã vượt hạn mức chi qua API trong ngày (mặc định 5.000.000đ/ngày cho mỗi khóa)Đặt tiếp vào ngày hôm sau, hoặc nhắn shop qua live chat nếu cần nâng hạn mức
Invalid order id (400) / Order not found (404)Mã đơn sai, hoặc đơn không thuộc tài khoản của bạnKiểm tra lại mã đơn nhận được lúc đặt
Rate limit exceeded (429)Gọi API quá nhanh (tối đa 300 lượt gọi/phút, trong đó đặt đơn tối đa 60 đơn/phút cho mỗi khóa)Giảm tần suất gọi rồi thử lại

Riêng khi đặt đơn (lệnh add) không thành công vì lý do xử lý, API trả về câu thông báo tiếng Việt dễ hiểu và tiền đã được hoàn về ví — bạn đọc nội dung thông báo rồi đặt lại sau ít phút nhé.

6. Lưu ý quan trọng

✅ Giá qua API bằng đúng giá trên web, tính bằng VNĐ cho 1.000 số lượng.
✅ Đơn đặt qua API dùng chung ví, và hiện trong lịch sử đơn hàng trên web như đơn đặt thường. Đơn lỗi, đơn hủy được hoàn tiền tự động như đơn web.
✅ Nếu bạn vô tình gửi trùng cùng một lệnh đặt đơn trong vòng vài giây, hệ thống trả về mã đơn cũ — không trừ tiền hai lần.
⚠️ Mã giảm giá không áp dụng cho đơn đặt qua API.
⚠️ Giữ khóa API như giữ mật khẩu: đừng đăng công khai, đừng gửi cho người lạ. Lộ khóa thì thay khóa mới ngay trong trang Tài khoản.

7. Câu hỏi thường gặp

Dùng API có mất thêm phí không?
Không. Bạn chỉ trả tiền các đơn như đặt trên web, giá bằng nhau.

Một tài khoản có mấy khóa API?
Mỗi tài khoản có 1 khóa đang dùng. Cần khóa mới thì bấm "Thay khóa", khóa cũ ngừng hoạt động ngay.

API có đủ gói như trên web không?
Có, toàn bộ gói đang bán trên web đều có trong lệnh services, giá cập nhật theo web.

Đặt đơn qua API có được hoa hồng giới thiệu như đơn web không?
Có, đơn qua API vẫn tính hoa hồng 2% cho người giới thiệu như đơn đặt bằng ví trên web.

Gặp lỗi không tự xử lý được thì hỏi ở đâu?
Nhắn cho shop qua live chat trực tiếp trên trang chủ, gửi kèm mã đơn (nếu có) để shop kiểm tra nhanh cho bạn nhé.
